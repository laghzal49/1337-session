# LazyVim

Launch `nvim` from a new terminal, or run `exec zsh` to refresh aliases.
Theme: Ayu Dark. Terminal font: Maple Mono NF, 18pt in Kitty.
Python: ty language server, Ruff linting and format on save.

Press Escape before leader shortcuts:
- Space e: file explorer
- Space Space or Space f f: find files
- Space /: search project
- Space g g: Git
- Ctrl+/: terminal
- Space c f: format
- gd: definition; K: documentation
- :w saves; :wq saves and quits

Kitty font settings reload with Ctrl+Shift+F5; a new Kitty window also uses them.
